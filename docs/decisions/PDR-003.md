# PDR-003: Corpus fresh start — zero rows carry over from the predecessor's dataset

**Date**: 2026-08-19
**Status**: Accepted

## Decision

No dataset content migrates from `intent-recovery-model`'s `datasets/gold/`
into this repository — **total** fresh start, including tiers not authored
by ChatGPT (`gold_v1.1`, generated by Gemini, and `gold_v1.2`, authored by
Claude). `datasets/gold/` in this repository starts empty and is populated
only by v2.0's own, newly-authored generation process.

`real_validation.jsonl` and `real_holdout.jsonl` are currently empty (zero
records) in the predecessor repository, so no content question applies to
them directly — but this repository's own `training/DATASET_SPEC.md` removes
the predecessor's rule permitting ChatGPT-assisted drafting for
`real_validation.jsonl` entirely, rather than re-labeling it to Gemini. The
"real" tier's point is to be uncontaminated by any generative model,
human-authored only — the predecessor's spec had a latent gap here that
this repository closes at zero cost, since both files start empty either
way.

## Reasoning

Even the non-ChatGPT-authored tiers (`v1.1`, `v1.2`) were shaped under a
taxonomy, category structure, and review methodology that ChatGPT
co-architected as the predecessor's "dataset & evaluation architect" — a
structural role, not just a content-authorship one (see the predecessor's
`docs/vision/NORTH_STAR.md`). Carrying those rows forward would mean this
repository's dataset still reflects OpenAI-tooling-shaped process decisions,
even where no individual row was OpenAI-generated. A total fresh start
avoids having to draw and defend a row-by-row line between "shaped by the
old process" and "not," and makes the "this corpus was built entirely under
the new process" claim simply true rather than approximately true.

`google/flan-t5-base` (the base model) is unaffected by this decision — it's
a third-party, Apache 2.0-licensed model with no OpenAI involvement, and
carries forward as the intended base model for v2.0.

## Scope

- `datasets/gold/`: empty at this repository's creation; populated only by
  work done under this repository's own, newly-authored `TAXONOMY.md`,
  `CATEGORY_REFERENCE.md`, `REVIEW_GUIDE.md`, and `DATASET_SPEC.md`.
- `datasets/synthetic.jsonl`: does not exist yet.
- `training/checkpoints/`: none exist yet; no predecessor checkpoint is
  reused as a starting point, since all 23 of the predecessor's checkpoints
  are downstream of ChatGPT-shaped dataset tiers.
- `datasets/real_validation.jsonl`, `datasets/real_holdout.jsonl`: created
  empty here; the ChatGPT-assist drafting allowance for `real_validation.jsonl`
  is removed from this repository's `DATASET_SPEC.md`, not carried forward
  even relabeled.
