# PDR-001: Discontinue OpenAI as a project collaborator; fork to a standalone v2.0 repository

**Date**: 2026-08-19
**Status**: Accepted

## Decision

This project permanently stops using OpenAI products (ChatGPT, Codex) as
tools or collaborators, effective 2026-08-19. Development continues as a
two-model partnership: **Claude (Anthropic)** for code and corpus work,
**Gemini (Google)** for dataset generation — with the product owner in the
same final-decision-authority role as always.

The clean break is a **brand-new standalone repository**
(`intent-recovery-model-v2`), not a branch or history rewrite of the
predecessor. The predecessor repository, `intent-recovery-model`
(https://github.com/ThisIsJohnnyt/intent-recovery-model), keeps its
committed history exactly as it is — nothing there is deleted, hidden, or
retroactively edited — and is separately marked as superseded/archived
through GitHub's own repository-metadata tools, not through a rewrite of
`main`.

This repository's corpus starts from zero: no rows carry over from the
predecessor's dataset, including tiers not authored by ChatGPT — see
[PDR-003](PDR-003.md) for why even those don't carry over. This repository's
governance documents (this one included) are freshly authored, not copied
forward; the predecessor's own documentation stays as-is in its own repo.

## Reasoning

The product owner made this decision on his own research into how OpenAI
handles the safety and downstream use of the content its products produce,
informed by public reporting and litigation concerning OpenAI, weighed
against his personal values. This PDR records that the decision was made
and what it changes about this project; it does not itself make legal or
factual claims about OpenAI beyond that — those are the product owner's own
conclusions, reached outside this project.

A fork to a new repository, rather than a branch or in-place rewrite, was
chosen because:

- The predecessor repository is public, with 152 commits carrying
  ChatGPT/Codex fingerprints throughout, and a public model release
  (`intent-recovery-model-v0.1.0`) trained on data tiers ChatGPT was
  involved in producing. Rewriting that history would falsify a public
  record rather than correct one.
- Existing open-license grants on the predecessor's dataset content
  (CC BY 4.0 for `gold_v1.0`–`v1.2.3`, and the CC BY-NC-SA 4.0 that replaced
  it) are legally irrevocable once published — no repository action can
  retract them. The honest response is to label the old material clearly and
  build the new material separately, not to pretend the old material never
  existed.
- A clean, empty starting point makes "nothing here was touched by OpenAI
  tooling" a verifiable property of this repository (see this PDR's
  Verification note below), rather than a claim that requires trusting a
  file-by-file audit of a large, mixed-provenance history.

### What does and doesn't migrate

**Nothing migrates as files.** No dataset content, no trained checkpoints,
no governance-doc text, no code files copied verbatim from the predecessor.
Where the predecessor project learned something durable and unrelated to
authorship (engineering findings, process patterns worth keeping), that
knowledge is re-implemented fresh here, informed by but not copied from the
old repository. `google/flan-t5-base` (Apache 2.0, Google-published)
carries forward unchanged as the intended base model — it was never an
OpenAI dependency in the first place.

The predecessor's `training/gemini_generator_gate2/` pipeline (a Codex-
drafted, Claude-reviewed dataset-generation tool) is being architecturally
superseded, not migrated — its role is replaced by whatever concrete
Claude+Gemini tooling integration this project builds going forward (see a
future PDR once that's concrete), not by porting its code here.

### Verification

Anyone can check this repository directly:
- `git log`: every commit here postdates 2026-08-19 and has no predecessor
  ChatGPT/Codex-authored ancestor.
- No filename or content match for `chatgpt`/`codex` outside this PDR's own
  historical description of the predecessor.
- No dataset row, checkpoint, or governance-doc paragraph traces back to the
  predecessor repository.
