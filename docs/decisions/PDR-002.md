# PDR-002: License classes for v2.0 (re-derived, not inherited)

**Date**: 2026-08-19
**Status**: Accepted

## Decision

This project uses the same three license *classes* its predecessor arrived
at, re-derived here on their own technical merits rather than inherited as
text:

1. **Dataset and documentation**: CC BY-NC-SA 4.0
   (Attribution-NonCommercial-ShareAlike). Human-authored prose and
   examples, clearly copyrightable, no ownership doubt.
2. **Software** (`training/*.py` and other code): **PolyForm Noncommercial
   1.0.0**. A real software license — copyright grant, distribution/
   modification terms, an actual patent grant — at the cost of not legally
   forcing a fork's own new modifications to stay noncommercial.
3. **Released model weights**: no asserted copyright license. A plain
   request (acknowledgment + noncommercial use), explicitly not represented
   as a legally enforceable condition, given genuinely unsettled
   copyrightability. See [`MODEL_RELEASE_NOTICE.md`](../../MODEL_RELEASE_NOTICE.md).

License *texts* for classes 2 and 3's legal basis (Apache 2.0, for the
upstream base model; PolyForm Noncommercial, for this project's own code)
are copied verbatim into [`LICENSES/`](../../LICENSES/) — unmodified
third-party/standard legal boilerplate, not project-authored content.

## Reasoning

The predecessor project ([PDR-006](https://github.com/ThisIsJohnnyt/intent-recovery-model/blob/main/docs/decisions/PDR-006.md)
and [PDR-008](https://github.com/ThisIsJohnnyt/intent-recovery-model/blob/main/docs/decisions/PDR-008.md)
in `intent-recovery-model`) worked through this same question in detail, and
that reasoning holds on its own technical merits, independent of who
co-approved it there:

- **CC BY-NC-SA 4.0 for dataset/docs**: NonCommercial matches the intent
  that this project and its forks stay noncommercial; ShareAlike is the
  actual legal mechanism forcing a fork to preserve that restriction (a
  plain CC BY-NC 4.0, without ShareAlike, would stop commercial use but not
  require a fork to relicense its own derivative under the same terms).
- **PolyForm Noncommercial over CC BY-NC-SA for code**: CC's ShareAlike
  condition has no source-code-delivery requirement the way GPL-family
  copyleft licenses do, so it wouldn't reliably keep a fork's modifications
  inspectable even if chosen. CC licenses also explicitly exclude patent
  rights (CC BY-NC-SA 4.0 legal code §2(b)(2)). PolyForm Noncommercial is a
  real software license with an actual patent grant, at the honest cost of
  not forcing a fork's *new* additions to stay noncommercial — a tradeoff
  consistent with preferring clean, honestly-scoped terms over maximal
  enforcement.
- **Model weights left unlicensed, request-based instead**: whether trained
  model weights are copyrightable at all, and whether fine-tuned weights are
  a derivative of the base model or of the training data, is not a settled
  question (the U.S. Copyright Office's May 2025 Part III report on AI and
  copyright discusses this directly, including that weights substantially
  memorizing training data may constitute infringing copies of someone
  else's material, independent of the weights' own copyrightability).
  Asserting "these weights are licensed under [X]" would overstate what this
  project can actually grant. A plain request — acknowledge the project,
  use noncommercially — doesn't need that legal hook to be stated honestly.

Because this repository has no dataset content, no code, and no released
model yet, this PDR records the *policy* now, for every artifact class to
apply to as content is added, rather than waiting until each class has real
content to license.

## Scope

- No dataset content exists yet in `datasets/gold/`. This decision applies
  from the first real content committed here.
- No model has been released from this repository yet. `MODEL_RELEASE_NOTICE.md`
  and `THIRD_PARTY_NOTICES.md` are scaffolded now and will be completed with
  real provenance/hash verification when the first release is actually
  prepared.
- Private data (`datasets/real_validation.jsonl`, `datasets/real_holdout.jsonl`)
  remains unlicensed, excluded from version control, never published —
  consistent with the predecessor's PDR-004.

## What this PDR does not do

Does not obtain formal legal counsel. Does not perform a memorization/
output-provenance audit of any checkpoint (there are none yet). Does not
establish trademark protection for the project name.
